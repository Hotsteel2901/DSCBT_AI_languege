# DSCBT 编程语言教程

## 一、语言简介

DSCBT 是一门**编译型**编程语言，语法类似 Python 般简洁，但具备 C/Rust 般的静态类型系统和本地编译能力。编译器 `dsc` 将 `.dscbt` 源文件编译为原生 Windows 可执行文件（.exe）。

**设计理念：**
- 语法极简，缩进定义代码块（Python 风格）
- 静态类型，类型自动推断
- 编译为原生机器码，运行效率高
- 图灵完备（支持条件、循环、递归函数）

**语言得名：** DSCBT = DS Code Basic Test

## 二、安装与构建

### 前置要求

- Windows 操作系统
- MinGW-w64 (gcc) 或 Clang（C 编译器）

推荐安装 MinGW-w64：[https://www.mingw-w64.org/](https://www.mingw-w64.org/)

### 构建编译器

```batch
# 使用 build.bat 自动编译
build.bat

# 或手动编译
gcc -O2 -o dsc.exe dsc.c
```

### 使用编译器

```batch
# 基本用法
dsc.exe 源文件.dscbt

# 指定输出文件名
dsc.exe 源文件.dscbt 输出.exe
```

## 三、基础语法

### 3.1 注释

```
// 这是单行注释

/* 这是
   多行注释 */
```

### 3.2 变量

使用 `let` 关键字声明变量，类型自动推断：

```
let x = 10          // 整数 (int)
let y = 3.14        // 浮点数 (flt)
let 名字 = "你好"    // 字符串 (str)
let 标志 = tru      // 布尔值 (bol)
```

变量可以被重新赋值：

```
let x = 10
x = 20              // x 现在是 20
x = x + 5           // x 现在是 25
```

### 3.3 数据类型

| 类型名 | 关键字 | 说明              | 示例       |
|--------|--------|-------------------|------------|
| 整数   | int    | 64位有符号整数    | `10`, `-5` |
| 浮点   | flt    | 64位双精度浮点数  | `3.14`     |
| 字符串 | str    | 字符串字面量      | `"hello"`  |
| 布尔   | bol    | 真/假值           | `tru`,`fal`|

类型注解（可选）：

```
let x: int = 10
let y: flt = 3.14
let s: str = "hello"
let b: bol = tru
```

### 3.4 输出与输入

```
// 输出
prt("你好，世界")
prt(42)
prt(3.14)
prt(tru)

// 输入整数
let 年龄 = inp("请输入年龄: ")
prt(年龄)
```

### 3.5 运算符

**算术运算符：**

```
let 和 = a + b      // 加法
let 差 = a - b      // 减法
let 积 = a * b      // 乘法
let 商 = a / b      // 除法
let 余 = a % b      // 取模（求余）
```

字符串也可以使用 `+` 拼接：

```
let 问候 = "你好, " + "世界"
prt(问候)           // 输出: 你好, 世界
```

**比较运算符：**

```
a == b              // 等于
a != b              // 不等于
a < b               // 小于
a > b               // 大于
a <= b              // 小于等于
a >= b              // 大于等于
```

**逻辑运算符：**

```
a & b               // 逻辑与 (AND)
a | b               // 逻辑或 (OR)
!a                  // 逻辑非 (NOT)
```

**优先级（从高到低）：**
1. `!` `-`（一元）
2. `*` `/` `%`
3. `+` `-`
4. `<` `>` `<=` `>=`
5. `==` `!=`
6. `&`
7. `|`

## 四、控制流

### 4.1 条件语句

```
if 条件:
    语句...
els if 条件:
    语句...
els:
    语句...
```

示例：

```
let 分数 = 85

if 分数 >= 90:
    prt("优秀")
els if 分数 >= 80:
    prt("良好")
els if 分数 >= 60:
    prt("及格")
els:
    prt("不及格")
```

### 4.2 While 循环

```
whl 条件:
    语句...
```

示例：

```
let i = 0
whl i < 10:
    prt(i)
    i = i + 1
```

### 4.3 For 循环

```
for let 变量 = 初始值; 条件; 更新:
    语句...
```

示例：

```
for let i = 0; i < 10; i = i + 1:
    prt(i)
```

等价于 C 语言的 `for (int i = 0; i < 10; i = i + 1)`。

## 五、函数

### 5.1 函数定义

```
fn 函数名(参数1, 参数2, ...):
    语句...
    ret 返回值
```

示例：

```
fn 加法(a, b):
    ret a + b

fn 最大值(a, b):
    if a > b:
        ret a
    ret b

prt(加法(3, 5))      // 输出: 8
prt(最大值(10, 20))   // 输出: 20
```

### 5.2 递归

DSCBT 支持递归函数调用：

```
fn 阶乘(n):
    if n <= 1:
        ret 1
    ret n * 阶乘(n - 1)

prt(阶乘(5))         // 输出: 120
```

```
fn 斐波那契(n):
    if n <= 1:
        ret n
    ret 斐波那契(n - 1) + 斐波那契(n - 2)

prt(斐波那契(10))    // 输出: 55
```

### 5.3 返回类型注解

```
fn 除以(a: flt, b: flt): flt:
    ret a / b
```

如果没有 `ret` 语句，函数默认返回 0。

## 六、结构体

使用 `typ` 关键字定义结构体类型：

```

```

## 八、完整示例

### 示例 1：Hello World

```
prt("你好，世界！")
prt("欢迎使用 DSCBT 编程语言")
```

### 示例 2：计算 1 到 100 的和

```
let 和 = 0
let i = 1
whl i <= 100:
    和 = 和 + i
    i = i + 1
prt(和)
```

### 示例 3：判断质数

```
fn 是质数(n):
    if n <= 1:
        ret fal
    let i = 2
    whl i * i <= n:
        if n % i == 0:
            ret fal
        i = i + 1
    ret tru

// 打印 1 到 100 的所有质数
let 数 = 2
whl 数 <= 100:
    if 是质数(数):
        prt(数)
    数 = 数 + 1
```

### 示例 4：冒泡排序

```
let 数组 = [64, 34, 25, 12, 22, 11, 90]

let n = #数组
for let i = 0; i < n; i = i + 1:
    for let j = 0; j < n - i - 1; j = j + 1:
        if 数组[j] > 数组[j + 1]:
            let 临时 = 数组[j]
            数组[j] = 数组[j + 1]
            数组[j + 1] = 临时

// 打印排序结果
let k = 0
whl k < n:
    prt(数组[k])
    k = k + 1
```

### 示例 5：欧几里得算法求最大公约数

```
fn 最大公约数(a, b):
    whl b != 0:
        let 临时 = b
        b = a % b
        a = 临时
    ret a

prt(最大公约数(48, 18))  // 输出: 6
prt(最大公约数(100, 25)) // 输出: 25
```

## 十一、常见问题

**Q: 为什么需要 C 编译器？**
A: DSCBT 编译器将源码翻译为 C 代码，再调用 gcc/clang 编译为 .exe。这种设计让编译器可以专注于语法解析，而代码优化和本地代码生成交由成熟的 C 编译器完成。

**Q: 运行 exe 时缺少 DLL？**
A: 请确保 MinGW 的 bin 目录在 PATH 环境变量中，或将需要的 DLL 与 exe 放在同一目录。

**Q: 支持哪些平台？**
A: 目前仅支持 Windows。理论上编译器本身（dsc.c）可以在任何有 C 编译器的平台编译，但生成的可执行文件仅限当前架构。

**Q: 语言是图灵完备的吗？**
A: 是的。DSCBT 支持变量、条件分支、while 循环、函数递归——这些是图灵完备的充分条件。

## 十二、限制与未来计划

### 当前限制

- 没有指针或引用类型
- 没有动态内存分配（字符串拼接除外）
- 字符串拼接可能产生内存泄漏（使用后不释放）
- 没有标准库（仅有 prt 和 inp）
- 没有模块/导入系统
- 数组是固定大小的（编译时确定）
- 没有泛型

### 未来永远不可能添加

- 字符串类型改进
- 标准库函数
- 模块系统
- 更好的错误信息
- 调试信息支持
- 指针类型
