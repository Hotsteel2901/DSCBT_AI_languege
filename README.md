# DSCBT v4.0 — 编译为原生可执行文件

DSCBT（DSC = DS Code Basic Test）v4 是一门**编译型**动态语言：源文件 `.dscbt` 由 `dsc` 编译器直接生成机器码，再链接成独立的原生可执行文件。它不再包含字节码虚拟机，也不会把程序翻译成 C 或 Rust 源码。

系统学习请阅读：[《DSCBT 语言教程》](docs/DSCBT-教学指南.md)。教程覆盖构建、Hello World、猜数字、值/引用、类、数组、错误处理、项目实战，以及 v4 的优化与代码生成原理。

---

## 一、v4 是什么

```
.dscbt 源文件
   │  lexer / parser（Rust 实现）
   ▼
  AST ──► AST 优化器（常量折叠、代数化简、DCE、循环展开……）
   │
   ▼
 Cranelift IR ──► 指令选择 / 寄存器分配 / e-graph 优化 / 机器码编码
   │
   ▼
 目标文件（ELF / COFF）
   │  LLD 链接 + 内置 freestanding 运行时
   ▼
 独立可执行文件（Linux x86-64 / Windows x86-64）
```

- **真正的编译型语言**：表达式直接生成机器指令，没有解释器循环，没有运行时字节码。
- **不套壳**：编译器不会输出 C/Rust 源代码，也不调用 `gcc`/`rustc` 做二次编译；链接阶段只使用 LLD。
- **自带运行时**：DSC 的字符串、数组、对象、类型检查、格式化输出和错误处理由 `runtime/` 中的 `no_std` Rust 运行时提供，直接使用 Linux 系统调用或 Win32 API，不依赖 libc。
- **双目标**：Linux x86-64 与 Windows x86-64（PE32+）。
- **91 项优化**：前端、代码生成、运行时与 Cranelift 后端共 91 项，可用 `dsc --stats` 查看清单和实际命中次数。

## 二、构建编译器

### 前置条件

- Rust 1.85+（`cargo`、`rustc`）
- LLD 链接器（`ld.lld`、`lld-link`，或 rustup 自带的 `rust-lld`）
- 交叉编译 Windows 目标时：

```bash
rustup target add x86_64-pc-windows-gnu
```

Linux 主机通常还需要：

```bash
sudo apt install lld      # 或者使用 rustup 自带的 rust-lld
```

### 构建

```bash
cargo build --release -p dsc
```

生成 `target/release/dsc`。Windows 上可直接运行仓库根目录的 `build.bat`，它会执行同样的构建并把 `dsc.exe` 复制到根目录。

### 安装到 PATH（可选）

```bash
install -m 755 target/release/dsc /usr/local/bin/dsc
```

## 三、使用

```bash
# 编译并生成同名可执行文件（默认 Linux）
dsc hello.dscbt

# 指定输出文件
dsc hello.dscbt -o hello

# 编译为 Windows x86-64 可执行文件
dsc hello.dscbt --target windows -o hello.exe

# 打印优化清单与命中统计
dsc hello.dscbt --stats

# 版本与帮助
dsc --version
dsc --help
```

默认输出规则：

| 目标 | 未指定 `-o` 时的输出 |
|------|----------------------|
| `linux` | 去掉 `.dscbt` 后的文件名 |
| `windows` | 去掉 `.dscbt` 后的文件名 + `.exe` |

退出码：

| 退出码 | 含义 |
|--------|------|
| 0 | 编译并链接成功（运行程序时表示程序正常结束） |
| 1 | 参数、文件读取或链接错误 |
| 2 | 编译错误（词法/语法/语义/常量折叠） |
| 3 | 程序运行时错误 |

## 四、语言速览

### 4.1 注释

```
# 井号注释
// 双斜杠注释
```

### 4.2 变量

变量无需声明，赋值即创建；同一变量可以重新赋值为不同类型：

```
x = 10
x = "hello"
x = 3.14
```

模块顶层变量是全局变量，函数内部可以读写；函数内部首次赋值且模块顶层不存在同名全局变量时，创建函数局部变量。

### 4.3 值类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 64 位有符号整数，算术按二进制补码回绕 | `42`、`-7` |
| `float` | IEEE-754 双精度 | `3.14` |
| `str` | UTF-8 字节串 | `"你好"` |
| `bool` | `True` / `False` | `True` |
| `nil` | 空值 | 未初始化变量、缺失字段 |
| `array` | 动态值数组，固定长度 | `[1, "a", True]` |
| `object` | 类实例，引用语义 | `Point { x: 1, y: 2 }` |

真值规则：`0`、`0.0`、`""`、`nil`、`False` 为假；非零数字、非空字符串、数组和对象为真。

### 4.4 运算符

```
+  -  *  /  %          # 算术（整数除法向零截断）
== !=  <  >  <= >=     # 比较
and  or  not           # 逻辑（and/or 返回操作数，短路求值）
```

- `+` 任一侧为字符串时执行拼接，非字符串操作数按 `print` 的格式转换。
- `and` / `or` 与 Python 一样返回操作数本身，而不是强制转换为布尔值。
- 整数 `+ - *` 溢出回绕；除零、`INT64_MIN / -1` 是运行时错误。
- 字符串按字节字典序比较。

优先级（高到低）：

1. `not`、一元 `-`
2. `*`、`/`、`%`
3. `+`、`-`
4. `<`、`>`、`<=`、`>=`
5. `==`、`!=`
6. `and`
7. `or`

### 4.5 输出与输入

```
print("你好", 42, 3.14, True, [1, 2])
name = input("请输入年龄: ")     # 读取一行并解析整数前缀，返回 int
```

`print` 的多个参数以单个空格分隔，末尾换行。浮点数使用最短 `%g` 风格输出：

```
print(1.0 / 3.0)     # 0.3333333333333333
print(100000.0)      # 1e+05
print(0.00001)       # 1e-05
```

### 4.6 控制流

```
if score >= 90:
    print("优秀")
els if score >= 60:
    print("及格")
els:
    print("不及格")

while i < 10:
    i = i + 1

for i in range(5):
    print(i)
```

`range(n)` 迭代 `0 .. n-1`。循环变量在循环结束后保留：如果循环体没有给循环变量重新赋值，它等于 `n`；如果循环体给循环变量赋值，它保留最后一次赋值。循环体修改循环变量不会改变迭代次数。

### 4.7 函数

```
def add(a, b):
    return a + b

def log(msg):
    print(msg)                 # 没有 return 时默认返回 0

print(add(2, 3))
```

- 函数名前向引用与递归调用都可以。
- 参数和返回值类型标注是可选的“注释”，不影响运行。
- 最多 255 个参数；1–8 个参数通过寄存器直接传递。
- `return f(...)` 会把当前函数的返回槽直接转发给被调用函数，避免结果拷贝。

### 4.8 类（结构体）

```
class Point:
    x: int
    y: int

p = Point { x: 10, y: 20 }
print(p.x)
p.x = p.x + 5

class Rect:
    tl: Point
    br: Point

r = Rect { tl: Point { x: 0, y: 0 }, br: Point { x: 10, y: 10 } }
print(r.tl.x)
```

- 字段按声明顺序布局，字段偏移在编译期确定。
- 未提供的字段使用默认值：`int`/`bol` 为 `0`，`flt` 为 `0.0`，其他为 `nil`。
- 对象是引用类型；赋值与函数传参复制引用，不复制对象。
- 字段必须先在类中声明；对未知字段的静态访问是编译错误，动态访问是运行时错误。

### 4.9 数组

```
a = [10, 20, 30]
print(a[0])
a[1] = 99
print(len(a))        # 3
```

- 数组长度固定，越界是运行时错误。
- 元素可以是任意 DSC 值，包括嵌套数组和对象。
- 数组是引用类型，赋值与传参共享同一份数据。

### 4.10 内置函数

| 函数 | 说明 |
|------|------|
| `print(...)` | 输出任意个值，空格分隔，末尾换行 |
| `input(prompt)` | 输出提示、读取一行、返回解析出的整数 |
| `len(x)` | 数组长度、字符串字节数或对象字段数 |
| `type(x)` | 返回 `"int"`、`"float"`、`"str"`、`"bool"`、`"array"`、`"object"`、`"nil"` |

### 4.11 完整示例

```
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

class Point:
    x: int
    y: int

total = 0
for i in range(10):
    total = total + fib(i)

p = Point { x: total, y: len("dscbt") }
print("fib sum =", p.x)
print("name len =", p.y)
```

## 五、v4 优化清单（91 项）

完整清单和每个文件的命中次数可以通过 `dsc --stats` 查看。分组如下：

**前端 / AST（30 项）**：字符串驻留、类布局静态化、全局槽分配、编译期字段检查、常量折叠（整数/浮点/字符串/比较/逻辑/一元/len/type）、常量条件消除、`range(0)` 消除、小循环完全展开、死代码删除、空块/空分支删除、代数恒等与化简、`x*2 → x+x`、自比较、双重否定/取负、`and/or` 自吸收、类型事实传播与分支合并、纯表达式语句删除等。

**代码生成（35 项）**：局部变量 SSA 提升、全局变量直接寻址、BSS 零初始化、只读字符串段、静态字段偏移、字段读写快速路径、字段复合赋值融合、数组下标读写快速路径、整数算术/比较/取负内联快速路径、比较直接进入分支、短路分支、真值判断内联、寄存器直传参数、零参数调用特化、返回槽前传、临时槽复用、常量立即数、print 常量/单参数/零参数特化、函数级 section 等。

**运行时（6 项）**：字符串长度头部、字符串指针快速判等、64 KiB 缓冲输出、整数格式化快速路径、最短 `%g` 浮点格式化、无 libc 运行时。

**Cranelift 后端（20 项）**：指令选择、寄存器分配、SSA 构造、e-graph 重写、GVN、LICM、DCE、常量折叠、冗余分支消除、栈槽着色、复制合并、指令调度、分支松弛、调用约定降低、栈帧布局、地址模式折叠、强度削减、寄存器压力感知溢出等。

### 性能参考

在同一台机器上运行 `fib(30)`、3 万以内素数计数和 2 万次循环的混合基准：

| 实现 | 耗时 |
|------|------|
| v3 字节码解释器（`gcc -O2`） | 约 0.068 s |
| v4 原生可执行文件 | 约 0.016 s |

v4 约为 v3 的 4 倍。数字仅用于量级参考，实际结果取决于程序和机器。

## 六、限制

- 没有垃圾回收；运行时使用 64 MiB 静态堆，程序退出时统一回收。
- 数组长度固定，没有 `push` / `pop`。
- 没有模块或导入系统，一个 `.dscbt` 文件就是一个程序。
- 没有泛型、闭包、异常、`break` / `continue`。
- 没有标准库；内置函数只有 `print`、`input`、`len`、`type`。
- 目标平台固定为 x86-64 的 Linux 与 Windows。

## 七、仓库结构

```
compiler/           v4 编译器（Rust）
  src/lexer.rs      词法与缩进处理
  src/parser.rs     AST 解析
  src/opt.rs        AST 优化器
  src/codegen.rs    Cranelift 代码生成
  src/link.rs       目标文件写出与 LLD 链接
runtime/            freestanding 运行时（no_std Rust）
docs/               教程
*.dscbt             兼容性测试与示例
dsc.c               v3 字节码解释器（历史参考，v4 不再使用）
```
